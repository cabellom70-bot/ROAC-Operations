# TurnoMinero

## Visión

TurnoMinero es una aplicación móvil para registrar, seguir y cerrar eventos operacionales de equipos mineros en tiempo real.

Su objetivo es reemplazar el registro manual mediante WhatsApp y Excel por un flujo único de información.

La información debe registrarse una sola vez.

Desde ese único registro la aplicación generará automáticamente:

- Estado de la flota.
- Historial de cada equipo.
- Informe de entrega de turno.
- Trazabilidad completa.

---

## Problema actual

Actualmente las novedades se informan mediante WhatsApp.

Al finalizar el turno, una persona debe revisar todos los mensajes y volver a escribir la información en una planilla Excel para entregar el turno.

Esto genera:

- trabajo duplicado;
- errores;
- pérdida de tiempo;
- información difícil de buscar.

---

## Nuestra solución

Una aplicación donde:

1. Se selecciona el equipo.
2. Toda la información del equipo aparece automáticamente.
3. Se registra el evento.
4. Otro usuario puede atenderlo.
5. El evento permanece abierto.
6. Se actualiza durante la reparación.
7. Se cierra.
8. El informe del turno se genera automáticamente.

---

## Principios

- El equipo es el centro del sistema.
- Nunca pedir información que ya existe.
- Todo debe ser trazable.
- Mobile First.
- Menos toques.
- Más información.
- Simplicidad antes que complejidad.
- Cada versión debe ser funcional.
